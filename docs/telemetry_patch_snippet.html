Telemetry & Patching

SonarSniffer now supports optional telemetry reporting and a controlled, auditable two-way patch workflow for safe configuration updates (e.g., Garmin magic header variants). Patches are signed and can be auto-applied after approval. Code patches always require manual review.

  • Full implementation details & guide
  • Scripts: scripts/scan_garmin_firmware.py, scripts/submit_patch.py, scripts/poll_and_apply_patches.py
  • Security: HMAC-SHA256 signed patches via SONARSNIFFER_PATCH_SECRET

Note: Only safe config-like patches (currently magic_variants) are auto-applied; code changes must go through PR review.
