Installation

Windows — CLI

  • Download SonarSniffer-Windows-CLI-x64.zip and extract (e.g. C:\SonarSniffer\)
  • Run sonarsniffer-cli.exe or parse_cli.exe from that folder

Windows — Desktop

  • Run SonarSniffer-Setup.exe as Administrator (installs WebView2 if needed, MSI, and CLIs)
  • Or install SonarSniffer_*.msi directly — requires WebView2

macOS — CLI

  • Extract: unzip SonarSniffer-macOS-CLI-x64.zip -d ~/SonarSniffer
  • Make executable: chmod +x ~/SonarSniffer/sonarsniffer-cli ~/SonarSniffer/parse_cli
  • First run: System Settings → Privacy & Security → Allow

macOS — Desktop

  • Open the .dmg, drag SonarSniffer to Applications
  • If blocked: right-click the app → Open

Usage

Quick parse (inspect file)

parse_cli /path/to/file.RSD

Full pipeline (mosaic + video + all outputs)

sonarsniffer-cli /path/to/file.RSD --video --mosaic --curvelet --colormap amber

Available colormaps

amber · sonar · viridis · magma · inferno · plasma · ocean · iron · jet · grayscale

All options

sonarsniffer-cli <INPUT> [OPTIONS]

  --video           Export enhanced AV1/MP4 video
  --mosaic          Generate geo-referenced mosaic PNGs
  --curvelet        Apply curvelet denoising
  --soundtiles      Run SoundTiles feature alignment
  --colormap <name> Colormap for rendering
  --output <dir>    Override output directory
  --kml             Export KML ground overlay
  --kmz             Export KMZ package
  --mbtiles         Export MBTiles tileset
  --arcgis          Export ArcGIS-compatible GeoTIFF

Supported Formats

  • Garmin RSD — GT54, GT56, UHD, UHD2, Classic, LiveScope
  • Lowrance SL2/SL3 — Primary, Downscan, Sidescan
  • Humminbird DAT — Side imaging, down imaging
  • XTF — Extended Triton Format (survey-grade)
  • JSF — EdgeTech JSF format
  • Cerulean — Cerulean Sonar logs
